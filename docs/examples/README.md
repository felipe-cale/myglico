# Exemplos de relatórios

- [`relatorio-paciente-exemplo.pdf`](./relatorio-paciente-exemplo.pdf): PDF sintético de um paciente de exemplo, gerado por `scripts/generate_sample_patient_report_pdf.py`, com estatísticas do período, distribuição glicêmica, indicativo de hipo/hiperglicemia por hora, média glicêmica no período, detalhamento diário e todas as leituras do período.

Para regenerar o arquivo:

```bash
python3 scripts/generate_sample_patient_report_pdf.py
```
